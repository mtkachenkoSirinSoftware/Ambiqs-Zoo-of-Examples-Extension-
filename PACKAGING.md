# What this tarball is (phase 6)

Rebuild from this tree:

```bash
make dist          # writes dist/ambiq_kws_examples.tar.gz
make verify-dist   # extract + inclusion / exclusion checks
make ci            # host tests, then dist + verify
```

`make ci-firmware` additionally `nsx build`s `kws_clip` and `kws_uart` (no
flash). Needs `nsx` on `PATH` and a TTY or the `script -q` wrapper in README.

## In the archive

| Path | Why |
|---|---|
| `kws_core/` | shared frontend, helia runner, recognizer, flash-clip player |
| `kws_clip/` | example 1 — 1 s PCM in flash |
| `kws_uart/` | example 2 — host WAV over FIFO-poll UART |
| `kws_pdm/` | example 3 — EVB PDM MEMS |
| `assets/depgraph_r060_kd_int8.tflite` | the one shipping INT8 graph |
| `kws_uart/host/synthetic.wav` | the one identity WAV (same PCM as the flash clip) |
| `kws_uart/host/stream_wav.py` | host tool (`--list-ports`, `--dtr auto`) |
| `kws_uart/host/rpc_infer.py` | USB RPC INFER of 16000 int16 (not the usb_rpc toy) |
| `tools/embed_model.py` | Class A/B/C `--check` + C-array emit |
| `README.md`, `LICENSE`, `COVER.md`, this file | first-read + license |

Generated C arrays (`model/generated/kws_model_data.cc`, clip PCM) and
`nsx.lock` ship so `nsx build` works without re-running embed.

## Not in the archive

| Path / tree | Why |
|---|---|
| AmbiqSuite SDK | NSX pulls `nsx-ambiqsuite`; do not vendor a Suite tarball |
| `.venv`, `.venv-hpx*` | environment, not an example |
| `demo_a/`, `demo_b/`, `apollo510_kws_demo/` | research / dual firmware trees |
| `optimizationExperiments/`, `results/` | cascade notebooks and host tables |
| SNR mixers, ALSA host-mic, GATE essays | not the happy path |
| `modules/`, `cmake/nsx/`, `boards/`, `build/` | NSX clones and build trees |
| `kws_model_manifest.json` | absolute host paths |
| `host/generated/` | encoder interop blob; regenerated by host tests |

## Host CI (no EVB)

`make test` runs GoogleTest on `kws_core`, Python identity on clip/uart/pdm,
UART framing + C++ decoder interop, and `embed_model.py --check` on the
shipping `.tflite`. TensorFlow / LiteRT is not required for those checks.

Firmware link (`nsx build`) is optional in CI. Flash + SWO `pred=` is EVB work.
